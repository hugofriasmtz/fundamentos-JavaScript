## Sobre este repositorio

Este repositorio contiene mi guía personal de **JavaScript**, creada para
aprender, practicar y desenvolverme progresivamente en este lenguaje.

La idea es avanzar desde los fundamentos hasta temas más completos mediante
ejemplos sencillos y ejercicios propios.

## Contenido

La carpeta [`Basico/`](./Basico/) reúne los temas estudiados hasta ahora:

- Variables y tipos de datos.
- Operadores y estructuras condicionales.
- Strings, arrays, sets y maps.
- Bucles y funciones.
- Objetos y desestructuración.
- Propagación (*spread*).
- Clases, herencia y encapsulamiento.
- Gestión de errores.
- Métodos de la consola.
